Getting started

  1. Open the app and tap Open an example: a two-storey house with layered external walls, a door, four windows, a floor slab and a room.
  2. In Design, tap a wall to select it. Drag its end handle to reshape it, or type an exact length in the inspector. The wall tool draws new walls; the door and window tools place openings by tapping a wall; the room and slab tools drag out rectangles.
  3. 3D shows the same model as solids. Check tells you what is wrong and takes you there. Quantities is the take-off. Documents generates the PDF sheets and exports IFC, the schedules and the project file.

Frequently asked

How do I move a project to another device?

In Documents → Exchange → Project file, export a .bimproj file and send it to the other device (AirDrop, Mail, Files). There, press Import on the project screen, or open the file directly. This version has no cloud sync: projects move as files, so you always know where they are.

What opens the IFC file?

Any IFC 4 capable BIM application or viewer. The file contains real elements (IfcWallStandardCase, IfcDoor, IfcWindow, IfcSlab, IfcSpace) with their properties, not a mesh.

What languages does the assistant understand?

On iOS 26 and macOS 26 with Apple Intelligence, the description is read by Apple's on-device language model, in any language it accepts. On other systems it is read by a built-in vocabulary covering English, Romanian, German, Italian, Spanish and French. The screen tells you which one answered. Either way the layout is computed by a deterministic algorithm and nothing leaves the device.

Why does a quantity say "unmeasured" instead of a number?

Because the app does not invent numbers. A line with no usable rate, a rate in a currency other than the project's, or an element that cannot be measured is reported as such, with the reason, rather than shown as zero.

Keyboard shortcuts

  • Delete removes the selection; Escape cancels what you are drawing or clears the selection.
  • Arrow keys nudge the selection by one grid step.
  • ⌘Z / ⇧⌘Z undo and redo; ⌘S saves now (the app saves by itself after every change anyway).

Where are the projects kept?

In the app's own container on your device, as files. Every save is atomic and keeps a copy of the previous version. Uninstalling the app deletes them — export the project file first.

Does it do structural or services design?

No. It models architecture: walls, openings, slabs, rooms, storeys. The missing disciplines are absent from the app rather than approximated in it.

What to send when reporting a problem

  • What you were trying to do and what happened instead.
  • The device model and system version.
  • The app version, from the project settings.
  • If you can, the project file (.bimproj) or a screenshot.
